# Student Management System Features

## 1. Student Registration
Register students using their unique ID, name and email.

## 2. Student Management
View, update, search and delete student records.

## 3. Marks Management
Add and update subject-wise marks.

## 4. Grade Calculation
Calculate total marks, percentage and grades.

## 5. Data Storage
Store student information using JSON files.

## 6. Input Validation
Validate student details and marks.

## 7. Student Reports
Display student academic performance.

## 8. Automated Testing
Test the application using Python unittest.
