# Project Overview

## Objective
Build a small, understandable student record system using Python fundamentals.

## Intended users
A teacher or administrator who needs to maintain a simple local list of student records.

## Main workflow
1. Register a student with a unique ID.
2. Search, list, update or remove records.
3. Enter marks for each subject.
4. View the student's total, average percentage and grade.

## Data and privacy
Records are stored in a local JSON file. This prototype is not designed for production use or multi-user access. Do not store sensitive personal information in a public repository.
