# User Guide

1. Install Python 3.9 or newer.
2. Download or clone this repository.
3. Open a terminal in the project folder and run `python main.py`.
4. Choose a menu number and follow the prompts.
5. Select `0` to exit.

Student IDs must be unique. Email addresses must have a basic valid format. Subject marks must be between 0 and 100. Adding marks for an existing subject updates that subject's score.
