# GitHub.com commit guide (no VS Code)

This project is organized into 15 meaningful file additions. To create 15 commits directly on GitHub.com:

1. Create a new **public** repository named `student-management-system`.
2. Open the repository. For each numbered step below, use **Add file → Create new file**.
3. Enter the exact path, paste the content from the matching file in this ZIP, then select **Commit changes**.
4. Use the exact commit message shown. Repeat for all 15 steps.
5. Do not upload the ZIP itself as the project source; add the individual files at their paths.

## 15 commits

| # | File path | Commit message |
|---:|---|---|
| 1 | `README.md` | Add project overview and setup instructions |
| 2 | `.gitignore` | Add Python ignore rules |
| 3 | `requirements.txt` | Add project requirements |
| 4 | `src/__init__.py` | Initialize source package |
| 5 | `src/models.py` | Add student model and grade calculations |
| 6 | `src/validation.py` | Add student and marks validation |
| 7 | `src/storage.py` | Add JSON data persistence |
| 8 | `src/service.py` | Implement student management operations |
| 9 | `src/reports.py` | Add student report formatting |
| 10 | `src/cli.py` | Add interactive command-line menu |
| 11 | `main.py` | Add application entry point |
| 12 | `tests/test_models.py` | Test student model and grade calculation |
| 13 | `tests/test_service.py` | Test student services and persistence |
| 14 | `docs/PROJECT_OVERVIEW.md` | Document project objectives and workflow |
| 15 | `docs/USER_GUIDE.md` | Add end-user instructions |

The `LICENSE` file is included in the ZIP too. To preserve exactly 15 commits, add it later as an optional 16th commit, or include it with commit 15 by creating both files before clicking **Commit changes**.

## Important
These are genuine sequential commits because each step adds a different project file. GitHub's web editor commits each file addition. If GitHub's interface offers **Commit directly to the main branch**, choose it.
